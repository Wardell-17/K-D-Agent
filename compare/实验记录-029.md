## 踩坑清单（本次新增）

- **kd_dispatch.ps1 静默失效** → 现象：Start-Process 返回 pid 但日志文件从不创建、子进程秒死无报错 → 根因：DSH 沙盒阻断工作区外写入（及可能的派生进程限制）→ 修法：主会话注入注册表 keys 直接后台跑 orchestrator.py + 按需提权；派发脚本用法在本环境下不可用。
- **GBK 控制台炸 orchestrator** → 现象：架构师打回时 print "✗"(U+2717) 触发 UnicodeEncodeError 崩溃 → 根因：GBK 代码页无该字符（✅ U+2705 恰好在 GBK 中，之前一直没踩到）→ 修法：`PYTHONIOENCODING=utf-8` + `PYTHONUTF8=1` 环境变量注入，不改代码。
- **`pwsh -File` 用法与实际执行器不符** → 现象：`pwsh` 命令不存在 → 根因：harness 执行器是 Windows PowerShell 而非 pwsh → 修法：用 `& <脚本路径>` 直接调用；kd_dispatch.ps1 注释里的用法需修正。
- **verify 命令含 subprocess 嵌套引号在 GBK 控制台输出截断** → 现象：验收 3 的 Traceback 在 events.jsonl 里被截断难读 → 根因：控制台编码 → 已被 PYTHONUTF8 一并修复。
