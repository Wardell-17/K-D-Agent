### 2. DSH 版本管理：钉死制 → 过闸制（7eb3e9b / d4d5b87）

依赖治理的方案选型（对照"防腐层/Fork/哑终端/自动过闸"四案）：

- **哑终端定位已是事实架构**（027 会师后 DSH 只剩 UI + run_command + preset 位），正式扶正写进 README 6.1；
- 耦合面确认为仅三个接口：preset 文本 / shell 执行 / 文件约定（tasks/ 进、report.json 出）；
- **自动过闸脚本 `compare/smoke_dsh.py`**：七盏灯——
  preset 静态契约 ×2（文件存在 + persona 纪律锚点）、
  派发链路 ×4（注册表 keys / kd_dispatch.ps1 / orchestrator 可编译 / 接口契约锚定
  `--cards` `--resume` `report.json` `cost.jsonl` `budget` `depends_on`）、
  端到端烟题 ×4（真实跑一道已知答案卡：report pass + engineer/architect 双角色入账 + 产物正确）。
  全程 12~30 秒、约 ¥0.01。
- 如实标注的边界：preset 在 DSH 界面的真实加载无法从外部断言，
  升级后需肉眼确认一次（10 秒），脚本结尾自带提醒。
