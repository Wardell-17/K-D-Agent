## 踩坑清单（本次新增）

- `pip install zstandard` 沙箱下 Permission denied（temp 目录 ACL）→ 根因：沙箱拦截 pip 解包写临时文件，即使 TMP 重定向到工作区仍被拒 → 修法：urllib 直下官方 wheel + `zipfile.extractall` 手工解包到工作区，绕过 pip 成功。
- `ZstdDecompressor().decompress()` 报 "could not determine content size in frame header" → 根因：DSH 会话 zstd 流无 content size 头 → 修法：`stream_reader(read_across_frames=True)`。
- 会话文件 mtime 不可靠（首次列出=createdAt，稍后刷成最后事件时间）→ 修法：以文件内事件时间戳（首/末事件 time）为准，"最近修改"按文件内最后事件时间排序。
- 当前运行中的会话（415f03c9）统计数字持续增长 → 账本是运行时刻快照，报告需注明。
- PowerShell `>` 重定向把 python 输出写成 UTF-16 → 用 `cmd /c "python ... > file"` 保留 UTF-8。
