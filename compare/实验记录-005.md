## 踩坑清单（本次新增）

- 旧版直接报错（Python 3.12 无 compression.zstd、无 zstandard）→ 根因：回退链只到 pip 包，无 vendored 兜底 → 修法：合并脚本增加 `_libs` 回退层，`Path(__file__).parent / "_libs"` 定位，随脚本归位。
- `get_zstd()` 回退链 `if not attempts:` 门控 bug → 根因：首个尝试失败 append 后 attempts 非空，后续 `if not attempts` 全部跳过，报错只列一条 → 修法：改为顺序 try/except 结构。
- `assistant/chunk` usage 兜底重复计数 → 根因：新版本会话中 chunk(usage) 块先于首条 `assistant/message` 出现，运行时 `saw_msg_usage` 门控把首条 chunk usage 重复计入（9da9ba61 多计 8,746 输入/73 输出）→ 修法：预扫描 `has_msg_usage` 后再决定是否用 chunk 兜底。
- `assistant/chunk` finish 块的 `replayState` 误计 model_attr → 根因：finish 块先于首条 message 出现时多计 1 次模型调用归属（主会话显示 36 vs 实际 35）→ 修法：该分支只作 model_seen 兜底显示，不计数。
- config.yaml deepseek 缓存命中 ¥0.2 与 2026-08-13 公告 ¥0.02 有出入 → 取舍：按任务要求以 config.yaml 口径为准（影响 8/14 会话的 cache 成本估算），脚本注释注明差异，待 config.yaml 更新后同步。
- `harness-test2/compare` 目录在上轮交付归位时被删除（仅实验记录 004 移入官方路径）→ 本轮重建目录与 `_libs`（重新从 PyPI 下载 wheel 解包，zstandard 0.25.0）。
