# 实验记录 014 —— 时效性裁决：Tavily 抓到旧口径，是能力问题还是技巧问题？

- 日期：2026-08-18
- 实验人：Wardell
- 关联：013（Tavily 550 万旧口径 vs DSH 原生 600 万新口径，留下争议）；
  本文回答争议并顺带实测免费兜底链的真实可用性

## 背景与假设

013 中 Tavily 抓到深圳 550 万（2024-08 口径），DSH 原生抓到 600 万+（2026-01 口径）。
两种解释：

- **能力说**：Tavily 对国内政务数据的索引时效性天然弱
- **技巧说**：查询词未带时间约束，Tavily 按历史权重返回了"关联度最高"的旧文

014 前置改动：检索层升级为可插拔 driver（任务卡 frontmatter 支持 `search_backend`），
工程师系统提示固化时效性纪律——**查询词必须带时间约束，结论必须附数据发布时间**。

## 对照设计

同一张任务卡（三条电动车事实清单，与 012/013 完全同题），仅改后端路由：

| 组 | 后端 | 运行位置 |
|---|---|---|
| A | `search_backend: tavily`（强制） | MVP runs/20260818-180211 |
| B | `search_backend: ddg`（免费兜底） | MVP runs/20260818-180431 |

## 结果

### A 组（Tavily + 时效纪律）：3/3 正确，抓到 2026 新口径 ✅

```
截至2025年12月，深圳市登记上牌电动自行车已超过600万辆 | 深圳交警（21经济网、证券时报2026年报道）
```

对比 013-B 的"550 万（2024-08）"——**同一工具、同一任务，仅加了查询词时间约束纪律，
就抓到了与 DSH 原生搜索同级的最新口径**。

### B 组（DuckDuckGo）：检索工具完全失效，透明降级 ⚠

- DDG html/lite 端点均返回 **HTTP 202 反爬拦截页**（对数据中心 IP 封锁）；
  Bing 直连返回 Google Docs 填充页、代理出口返回奥兰多酒店页——免费 HTML 抓取
  在当前网络环境全部不可用。
- 工程师 web_search ×7 全部落空后，**遵守"无工具则凭已有知识填写并标注"的卡片纪律**，
  逐条标注"web_search不可用未核实"，没有假装检索过——012 加固的诚实性纪律生效。
- 但幻觉随之而来：事实 1 写成"2024年11月1日实施"（旧国标 GB 17761-2018 口径），
  再次反面印证 012 结论——**无检索 = 幻觉复发**。

## 裁决：是技巧问题

**013 的口径差距根因是查询词未带时间约束，不是 Tavily 的索引能力缺陷。**
时效性问题在 Prompt 层（纪律）治理，而不是靠换更贵的工具治理。

## 架构推论（三条）

1. **Tavily 主力地位确认**：可审计 + 带纪律后时效性达标，1000 次/月额度的
   精细化管理（去重/引用制复用）重要性进一步上升。
2. **免费兜底链名存实亡**：ddg 驱动保留但已标注"当前环境不可用"，
   auto 降级链实际等于 tavily-only。若 Tavily 额度耗尽，系统会诚实失败
   （并标注未核实），而不会静默降级到垃圾信源——这是可接受的故障姿态。
3. **DSH 原生搜索的定位不变**：Harness 线日常主力（免费包含、时效最强），
   但用量不可审计；MVP 线继续 Tavily。013 结论维持，014 补上了"为什么"。
